## Текущие проекты

### AI-reviewer
инструмент командной строки, который проверяет научную статью в формате .docx с помощью агентов AI. Каждый агент проверяет статью на соответствие одному из критериев академического написания, например, краткости или грамотности. Этот инструмент объединяет результаты в отчет по каждому абзацу, поэтому проблемы с академическим стилем легко найти и устранить перед публикацией. Он предназначен для авторов научных статей, а также для рецензентов и редакторов, которые проверяют статьи перед публикацией.

### PrintingHouse

Система расчёта стоимости тиражей для типографии.

Позволяет рассчитывать стоимость сложносоставных тиражей, включающих:

* многополосную печать;
* различные типы печати;
* специфические сборные работы.

**Стек:**

`Python` `FastAPI` `SQLAlchemy` `Alembic` `Pytest`
`JavaScript` `React` `PostgreSQL`

### VSRT-Lang

Веб-приложение для изучения иностранных языков с помощью карточек.

Пользователь создаёт учебные сессии и формирует в них пул слов. Система автоматически дополняет каждую запись информацией о значении слова, синонимах, контекстах использования и другими связанными данными.

После формирования набора пользователь может:

* изучать слова в веб-приложении;
* формировать и печатать физические карточки для обучения.

Приложение построено на основе микросервисной архитектуры:

* веб-клиент реализован на `React`;
* backend реализован на `Go`;
* отдельный сервис обработки и перевода слов реализован на `Python`.

**Стек:**

`Go` `pgx` `JWT`
`Python` `NLTK` `Pytest`
`JavaScript` `React`
`PostgreSQL`
